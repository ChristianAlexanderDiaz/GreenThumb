# 🌱 GreenThumb - Plant Care Management iOS App

A comprehensive iOS application built with SwiftUI that helps users manage their plant collection, track watering schedules, and identify plant diseases using integrated APIs.

## 📱 Features

- **Personal Plant Collection**: Add, edit, and organize your plants by location
- **Smart Watering Tracker**: Set and track watering schedules with visual charts and history
- **Plant Disease Detection**: Identify plant diseases using integrated plant disease API
- **Plant Database Integration**: Search and explore plants using Perenual API
- **Photo Management**: Capture and track plant growth with photo documentation
- **User Authentication**: Secure login system with password reset functionality
- **Dark/Light Mode**: Full theme support with user preference persistence
- **Core Data Integration**: Robust local data storage and management
